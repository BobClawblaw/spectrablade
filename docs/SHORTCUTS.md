# Keyboard shortcuts

SpectraBlade's keys as it ships. Window > Keyboard Shortcuts... lists every command with the keys you have set; change them there, export and import them, or pick another key set. A command not listed here has no key until you give it one.

In the multitrack view the same keys act on clips where that makes sense: Delete deletes the selected clip, Cmd-A selects every clip, and Cut, Copy and Paste work on clips.

## With the mouse

| Action | How |
|---|---|
| Select the whole file | Double-click the waveform or spectrogram |
| Scrub (hear the sound as you drag over it) | Drag along the ruler above the waveform, while stopped |
| Select a band of frequencies | Option-drag in the spectrogram |
| Draw round frequencies (lasso tool) | Drag in the spectrogram; Shift-drag adds |
| Paint over frequencies (brush tool) | Drag in the spectrogram; Shift-drag adds |
| Draw a note clip (Draw tool) | Drag along an instrument track's lane in the multitrack view (below the tracks makes a track) |
| Cut a clip where it is clicked (Split tool) | Click the clip in the multitrack view |
| Stretch a clip, audio or notes (Stretch tool) | Drag the clip's edge in the multitrack view (Option-drag does it with the Select tool, for audio) |
| Join a note clip with the next on its track (Glue tool) | Click the clip in the multitrack view (or Merge with Next in its menu) |
| Fade in or out | Drag the handle at the waveform's top-left or top-right corner; drag up or down to bend the curve |
| Remove a fade | Double-click its handle |
| Rename a marker | Double-click it |
| Size the waveform and spectrogram | Drag the line between them |
| Zoom vertically | Option-scroll over the waveform |
| Maximise a group of panels, or put the others back | Double-click its tab, or use the ⋯ menu at the right of its tabs |
| Go to a time, or set the selection by its times | Click the cursor's or the selection's time under the editor |
| Show an open file | Click its tab over the editor |
| Close an open file | Click the × on its tab, or right-click the tab |
| Move a panel | Drag its tab onto another panel's edge, onto its middle (as a tab), or out of the window (to float it) |

## Effect dialogs

Every settings dialog in the Effects menu, and Clip Gain and Normalize Clip in the multitrack view (Insert Silence, Trim Silence and the silence finders have no preview; the generators' preview plays what they would put in at the cursor):

| What | Keys and mouse |
|---|---|
| Start or stop the preview | `Space` (not while typing a value) |
| Apply | `Return` |
| Cancel | `Escape` |
| Step a value up or down | mouse wheel over its slider or value, or `Up` / `Down` (also `Right` / `Left`) when it has the focus |
| Step by a tenth | hold `Shift` while turning the wheel or pressing the key |
| Step a menu | mouse wheel over it |
| Set a value back to where it started | double-click its slider |

## Inside panels

Keys a panel handles itself while it has the focus. They are not commands: they can't be changed in Window > Keyboard Shortcuts (which lists them after the commands, for reference) and clash with no command's key, since they work only there.

| Panel: what | Keys |
|---|---|
| Piano Roll: move the selected notes a semitone up or down | `Up` / `Down` |
| Piano Roll: move the selected notes an octave up or down | `Shift-Up` / `Shift-Down` |
| Piano Roll: move the selected notes a grid step earlier or later | `Left` / `Right` |
| Piano Roll: move the selected notes a quarter of a grid step | `Shift-Left` / `Shift-Right` |
| Piano Roll: remove the selected notes | `Delete` / `Forward Delete` |
| Piano Roll: select every note | `Cmd-A` |
| Sound Library: insert the selected sound at the cursor | `Return` |
| Sound Library: play or stop the selected sound | `Space` |
| Sound Library: rate the selected sounds (0 clears the rating) | `0` to `5` |
| Sound Library: mark the selected sounds as favourites, or unmark them | `F` |
| Keyboard: the white keys from C, an octave and a third | `A` to `L` and `;` |
| Keyboard: the black keys between them | `W` `E` `T` `Y` `U` `O` `P` |
| Marker List: rename the selected marker | `Return` |
| Marker List: remove the selected marker | `Delete` |
| Effect dialogs: start or stop the preview | `Space` |
| Effect dialogs: apply | `Return` |
| Effect dialogs: cancel | `Escape` |
| Effect dialogs: step the focused value (Shift: by a tenth) | `Up` / `Down` |
