# Dogfooding log

Feature work stopped at 0.14.7, and started again at 0.15.0 for one line (instruments, MIDI and automation; the [roadmap](ROADMAP.md) has what landed). From 0.14.7 to 1.0.0, each release fixes what real use turns up. This is the list: every problem found by using the app, in the order it was reported, with the version it was found in, what was wrong, the milestone that fixed it (see the [changelog](CHANGELOG.md)) and the release that carries the fix. Each has an [issue](https://github.com/BobClawblaw/spectrablade/issues) as well, closed against the commit that fixed it. A fix that is on main but not yet in a release (so in a build from the source, not in a downloaded disk image) reads "on main" until a release carries it. Problems still open stay at the top until a fix lands. New ones can be reported as issues or straight into this list.

1.0.0 is a round of use that adds nothing here.
